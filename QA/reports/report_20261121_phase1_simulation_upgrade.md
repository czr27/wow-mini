## 1. 测试范围与需求对齐

本次测试针对用户提出的最新 5 大核心打本仿真反馈与机制要求进行全链路端到端回归验证：
1. **队伍阵容严格5职业互不重复与自动补全顶替**：
   - 无论玩家选择任何职业进入（DK、德鲁伊、萨满、法师、潜行者），小队严格由 1T+1H+3DPS 组成。
   - 剩余 4 个 slot 由其余 4 个不同职业精确补全，杜绝重叠职业。
2. **经典矩形团队框架与 HoT 扇形转圈冷却/持续时间遮罩**：
   - 框架重构为魔兽世界经典 Grid/Compact Raid Frame 长方形（高度 56px 紧凑长方形色块）。
   - 去除 AI 队友冗余读条，只展示玩家自己与 Boss 施法条。
   - 玩家对队友施加的 HoT/Buff（如回春术、生命绽放、激流、骨盾）在方块右上角以 20×20 像素图标呈现，并使用 CSS `conic-gradient` 顺时针旋转扇形展示剩余有效时长，叠层数与倒计时秒数实时显示。
3. **本地技能栏扇形CD与就绪金色高亮**：
   - 冷却中的技能以顺时针旋转的黑色透明半圆扇面遮罩提示剩余冷却时间，并伴随数字倒计时。
   - 当技能完全冷却完毕可以释放时，赋予金色流光与呼吸外发光边框提示可释放。
4. **NPC移动速率平滑常速化与主坦拉怪策略**：
   - 去除大步百分比插值，采用恒定步长 `min(dist, 2.0)` 自然跑步速率赶路与走位，彻底杜绝瞬移。
   - 主坦在血线安全（HP >= 60%）时，主动将 Boss 引向右侧（x: 540, y: 190），使 Boss 背朝后排治疗与远程（x: 160-200），顺劈与正面技能不波及大团；血线危急时主动寻路进入绿色百花齐放/治疗之雨法阵受疗。
5. **影牙城堡 5 大首领与职业高精建模**：
   - 亚什布里男爵：维多利亚黑紫领主礼服与骨容，30%血以下觉醒黑暗大天使暗影虚空翼与全团暗影箭雨。
   - 席瓦莱恩男爵：半透明青碧灵体狼人幽魂，鬼火双目与灵体利爪。
   - 指挥官斯普林瓦尔：重铠亡灵骑士，单手持不洁颅骨塔盾，右手持邪恶符文巨剑与亵渎毒圈。
   - 沃登勋爵：炼金学会红绿双目目镜，腰挎四色药剂，双持冒烟烧瓶。
   - 高弗雷勋爵：高领深绯色长风衣与金丝眼镜，双持吉尔尼斯燧发手枪，射击伴随枪口火星与青烟。
   - 5大职业像素模型加入专属铠甲、鹿角、狼皮帽、奥术法袍、刺客面罩与专属武器发光特效。

## 3. 详细测试过程与断言记录

### 3.1 Suite 9: 队伍阵容补全差异化、矩形框架HoT扇面、动作条CD与首领视觉AI (`T-09`)
- **用例 1：5 职业互不重复队伍组合算法验证**
  - 测试遍历：模拟玩家分别以 DK、DRUID、SHAMAN、MAGE、ROGUE 进入副本。
  - 断言验证：每次生成的队伍严格包含 5 个互不相同的职业，`uniqueClasses.size === 5`。
  - 判定：**通过 (PASS)**。
- **用例 2：HoT 扇面剩余时长 (conic-gradient) 旋转弧度计算**
  - 测试输入：持续时间 12,000ms，剩余 6,000ms。
  - 计算角度：`sweepFraction = 6000 / 12000 = 0.5`，`sweepDeg = Math.round(0.5 * 360) = 180`度。
  - 判定：**通过 (PASS)**。
- **用例 3：技能动作栏扇形CD倒计时与就绪金色高亮状态计算**
  - 冷却完毕状态：`onCooldown === false` 且 `remainingCdMs <= 0` 判定为 `true`，触发金色高亮与发光边框。
  - 冷却中状态：`remainingCdMs = 7500`, `totalCdMs = 15000` 时，黑色透明扇面角度精确为 180 度。
  - 判定：**通过 (PASS)**。
- **用例 4：主坦智能拉怪控场走位 (血线安全引开Boss / 危险步入治疗圈)**
  - 血线安全（HP = 85,000 / 100,000 >= 60%）：目标坐标为 $(540, 190)$，将 Boss 引向右侧使 Boss 背对全团。
  - 血线危险（HP = 35,000 / 100,000 < 60%）：目标坐标重定向为绿色百花齐放/治疗之雨法阵 $(260, 210)$ 接受急救。
  - 判定：**通过 (PASS)**。
- **用例 5：亚什布里男爵黑暗大天使多阶段形态触发判定**
  - 当前血量 1,200,000 / 5,200,000（约 23.07% < 30%）：判定触发黑暗大天使形态，张开 120px 虚空暗影之翼。
  - 判定：**通过 (PASS)**。
