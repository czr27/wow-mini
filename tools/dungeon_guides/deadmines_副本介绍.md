# 副本介绍：死亡矿井（The Deadmines）

> 本文由开发工具 `tools/dungeon_guide_research.py` 合并多站攻略与本地引擎备注生成。
> 生成时间：2026-11-23 22:22

## 1. 概览

- **类型**：5 人副本（大灾变翻新；普通升级 / 英雄 85）
- **位置**：西部荒野月溪镇；部落可经荆棘谷或排队进本
- **主题**：大灾变翻新后由迪菲亚矿坑变为蒸汽朋克式地下工厂与海盗船。普通难度尾王为曲奇；英雄额外挑战梵妮莎·范克里夫（点笔记开启）。走位、炸弹与机械小怪是主旋律。
- **Boss 顺序**：
  1. 戈洛克托克 (Glubtok)
  2. 赫利克斯·碎轮 (Helix Gearbreaker)
  3. 死神 5000 (Foe Reaper 5000)
  4. 撕心船长利普斯纳尔 (Admiral Ripsnarl)
  5. 曲奇 ("Captain" Cookie)
  6. 梵妮莎·范克里夫 (Vanessa VanCleef，仅英雄)

## 2. 副本流程环节

1. 入口矿道清迪菲亚矿工 / 地精 → 开阔大厅
2. 1 号：戈洛克托克（法师大厅）
3. 通道 → 伐木场
4. 2 号：赫利克斯·碎轮（骑木虱）
5. 工厂区 → 收割机平台
6. 3 号：死神 5000（可上原型收割机打熔渣）
7. 上船甲板
8. 4 号：撕心船长利普斯纳尔（迷雾阶段点蒸汽）
9. 厨房区
10. 5 号：曲奇（普通尾王；注意坏食物）
11. 英雄：点地上笔记 → 梦魇连环 → 梵妮莎·范克里夫

## 3. 各 Boss 机制详解（合并多站）

### 1. 戈洛克托克（Glubtok）

**定位**：火焰/冰霜拳轮换 + 闪现；半血后花瓣与火墙

#### 阶段
- P1：火焰之拳 / 冰霜之拳轮换，换拳时闪现重置仇恨，T 立刻接回
- P2（约 50%）：中心轰炸火焰/冰霜花瓣，英雄会刷小花；火墙绕圈躲避

#### 技能 / CD / 要点

| 技能 | 英文 | CD/节奏 | 机制与注意 |
| --- | --- | --- | --- |
| 火焰之拳 / 冰霜之拳 | Fists of Flame / Frost | 轮换 | 近战勿站 T 旁叠伤害 |
| 闪现 | Blink | 换拳时 | 仇恨清空，T 预判接怪 |
| 火焰/冰霜花瓣 | Fire/Frost Blossom | P2 地面 | 看地躲开落点 |
| 火墙 | Fire Wall | 英雄 P2 | 绕 Boss 圆周移动，勿穿墙 |

#### 注意事项
- 半血后空间变小，远程优先站外圈

### 2. 赫利克斯·碎轮（Helix Gearbreaker）

**定位**：先打木虱，再打跳背的侏儒；胸弹散开

#### 阶段
- P1：赫利克斯骑在笨拙木虱上，铺粘性炸弹 + 胸弹；木虱会抓人砸墙
- P2：木虱死后赫利克斯每约 10s 跳到队友背上普攻并放胸弹

#### 技能 / CD / 要点

| 技能 | 英文 | CD/节奏 | 机制与注意 |
| --- | --- | --- | --- |
| 粘性炸弹 | Sticky Bomb | 持续铺地 | 定时爆炸，躲开落点 |
| 胸弹 | Chest Bomb | 随机点名 | 中弹者远离队友，免全团击飞 |
| 木虱砸击 | Oaf Smash | P1 | 被抓者承伤，尽快击杀木虱 |
| 跳跃 | Leap | P2 ~10s | 被骑者需额外治疗 |

#### 注意事项
- 胸弹是灭团主因；喊话跑出人群

### 3. 死神 5000（Foe Reaper 5000）

**定位**：散开躲收割；一人上原型收割机清熔渣

#### 阶段
- 全程：远离正面收割打击；过载时远离 Boss 乱跑路径
- 约 30%：安全限制解除，伤害翻倍，开减伤/爆发

#### 技能 / CD / 要点

| 技能 | 英文 | CD/节奏 | 机制与注意 |
| --- | --- | --- | --- |
| 收割 | Harvest | 点名落点 | 离开 Boss 行进路线与落点 |
| 过载 | Overdrive | 全场乱跑 | 远离 Boss |
| 熔渣 | Molten Slag | 持续刷出 | 原型收割机优先清熔渣 |
| 安全限制解除 | Safety Restrictions Off-line | ~30% | Boss 伤害大幅提升 |

#### 注意事项
- DPS/治疗开局散开；指定一人上机

#### 参考来源标签
- Icy Veins、Wowhead

### 4. 撕心船长利普斯纳尔（Admiral Ripsnarl）

**定位**：迷雾阶段点杀蒸汽；注意恐惧与冲锋

#### 阶段
- 甲板阶段：常规坦克战
- 迷雾：能见度下降，优先点蒸汽（Vapors），防止其长大

#### 技能 / CD / 要点

| 技能 | 英文 | CD/节奏 | 机制与注意 |
| --- | --- | --- | --- |
| 迷雾 | Fog | 阶段转换 | 集火蒸汽小怪 |
| 冲锋/恐惧类 | Charge / Fear-like | 战斗中 | 治疗预读；散开减连锁 |

#### 注意事项
- 蒸汽长大后极痛，宁可读条也要点掉

#### 参考来源标签
- Icy Veins

### 6. 梵妮莎·范克里夫（Vanessa VanCleef）
