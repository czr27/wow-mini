# 副本介绍：血色修道院（Scarlet Monastery）

> 本文由开发工具 `tools/dungeon_guide_research.py` 合并多站攻略与本地引擎备注生成。
> 生成时间：2026-11-23 22:23

## 1. 概览

- **类型**：5 人副本群（经典旧世 28–45；墓地/图书馆/军械库/大教堂）
- **位置**：提瑞斯法林地；庭院四个独立入口
- **主题**：四翼独立五人本，升级向宝地。图书馆杜安后的箱子开出血色钥匙，用于军械库与大教堂门（盗贼可开锁）。人形怪残血逃跑，卡视野与控场很重要。
- **Boss 顺序**：
  1. 审讯员韦沙斯 / 血法师萨尔诺斯（墓地）
  2. 驯犬者洛克希 / 奥法师杜安（图书馆）
  3. 赫洛德（军械库）
  4. 莫格莱尼 + 怀特迈恩（大教堂）

## 2. 副本流程环节

1. 约 30–32：墓地（审讯员韦沙斯 → 血法师萨尔诺斯；注意稀有）
2. 约 32–35：图书馆（驯犬者洛克希 → 奥法师杜安；拿钥匙）
3. 约 36–38：军械库（赫洛德；死后学徒潮）
4. 约 38–40：大教堂（可选法尔班克斯 → 莫格莱尼 → 怀特迈恩）

### 4. 莫格莱尼 + 怀特迈恩（Mograine & Whitemane）

**定位**：大教堂双王：先清礼拜堂全部小怪再开战

#### 阶段
- 打莫格莱尼至假死 → 怀特迈恩进场复活他
- 优先打断/集火怀特迈恩，再收莫格莱尼

#### 技能 / CD / 要点

| 技能 | 英文 | CD/节奏 | 机制与注意 |
| --- | --- | --- | --- |
| 复活 | Whitemane Resurrection | 阶段 | 打断怀特迈恩关键技能 |
| 神圣打击等 | Holy abilities | 战斗中 | 双目标治疗压力上升 |

#### 注意事项
- 开打前必须清光教堂小怪，否则会加入战斗
