> 对照代码：`DEV/packages/engine/src/bosses/*`  
> 日期：2026-11-23

## 总判

| 副本 | 完成度（机制保真） | 结论 |
| --- | --- | --- |
| 影牙城堡 | **约 55–65%** | 五王都有专属技能壳，但多数是「伤害事件」而非完整机制；可优先补细节 |
| 巨龙之魂 | **约 70–80%** | 八王均有专属模块（可玩简化版）；细节/英雄专属仍可继续打磨 |

## 一、影牙城堡（可完善，建议优先）

### 1. 亚什布里男爵 — 已有骨架，差「技能拆分与跳字治疗」

| 攻略要点 | 现状 | 建议 |
| --- | --- | --- |
| 窒息 → 全员 1 血 | ✅ 有 | 保持 |
| 暂缓处决：引导多跳 ~10%/跳，约定 1–2 跳再断 | ⚠️ 一次抬血 25%（Boss）/35%（玩家），非跳字 | 改成引导 tick（每秒一跳），打断截断后续跳 |
| 修补烂肉 25% 必断 | ✅ 有 | 保持 |
| 苦痛与折磨：可打断鞭笞 | ❌ 并入「苦痛灾厄脉冲」 | 拆出可打断单体/点名引导 |
| 毁坏之痛：叠暗影易伤 | ❌ 无 | 加可叠 debuff，缩放暗影伤害 |
| ≤20–25% 暗天使：只打灾祸 AOE | ⚠️ 仅脉冲加伤，其它技能不停 | 阶段锁：停修补/窒息节奏或提高灾祸频率 |

### 2. 席瓦莱恩男爵 — 缺「真增援」与「受疗减免生效」

| 攻略要点 | 现状 | 建议 |
| --- | --- | --- |
| 降疗诅咒 75% | ⚠️ 有 debuff 名与 DOT，**引擎无受疗系数结算** | 在 `applyHeal` 读 debuff 乘算（mortal_wound 同理） |
| 召唤狼人之灵 | ❌ 对随机后排直伤，无单位 | 生成临时敌方 Unit / 或可点选假人，T 嘲讽+击杀 |
| 阴影面纱全团伤 | ✅ 简化 AOE | 可保留 |

### 3. 指挥官斯普林瓦尔 — 与攻略差最大（建议第二优先）

| 攻略要点 | 现状 | 建议 |
| --- | --- | --- |
| 哀嚎卫兵 / 痛苦军官增援 | ❌ 无 | 开场+周期性刷怪；卫兵 AOE 沉默、军官可锁 |
| Unholy Empowerment 可打断（小怪给 Boss 赋能） | ❌ 变成全团暗影脉冲且不可打断 | 小怪读条赋能；打断失败叠不洁能量 |
| 背信之盾：正面锥形 | ❌ 只打主坦一下 | 复用高弗雷扇形预警（CONE） |
| 亵渎毒圈 | ✅ 地面圈 | 保持；T AI 甩圈更佳 |
| 羞愧之语：每 3s 扣 5% | ❌ 无 | 低血或能量满时上永久 DOT% |

### 4. 沃登勋爵 — UI 有绿红文案，缺「动/静判定」

| 攻略要点 | 现状 | 建议 |
| --- | --- | --- |
| 绿：必须移动消层 | ❌ 全员挂 DOT，与移动无关 | `onTick` 检测位移：动则消层/免伤，停则叠毒 |
| 红：必须静止 | ❌ 同上 | 动则额外爆伤或叠 Toxic Catalyst |
| 冰碎片：地面落点 | ❌ 全团瞬间冰伤 | 落点圈 + 踩中受伤（可参考亵渎） |
| 霜/毒药瓶飞弹 | ❌ 无 | 可选：点名落点预警 |

### 5. 高弗雷勋爵 — 相对最完整，补「食尸鬼」即可

| 攻略要点 | 现状 | 建议 |
| --- | --- | --- |
| 双枪弹幕锥形 | ✅ 有预警+扇形 | 避免 `setTimeout`，改引擎时间轴/`onTick` |
| 诅咒之弹可断可驱 | ✅ | 保持 |
| 重伤降疗叠层 | ⚠️ buff 有，**降疗未进公式** | 与席瓦莱恩共用受疗系数 |
| 召唤嗜血食尸鬼 | ❌ 无 | 弹幕前刷薄血小怪；可用弹幕清（成就 Bullet Time） |

### 影牙完善优先级（建议）

1. **全局**：治疗量结算支持「降受疗」debuff（席瓦莱恩、高弗雷）  
2. **沃登**：绿走红停位移判定（体验差异最大）  
3. **亚什布里**：暂缓处决跳字 + 苦痛/易伤拆分  
4. **斯普林瓦尔**：锥形 + 小怪赋能（工作量最大）  
5. **高弗雷**：食尸鬼；弹幕改确定性计时  
6. **席瓦莱恩**：真召唤物

## 三、跨系统缺口（两副本共用）

1. **Debuff 数值未进公式**：降受疗、护甲削减、暗影易伤等只有表现层。  
2. **增援/召唤**：多数「召唤」是直伤冒名，缺少可击杀 Unit。  
3. **走位判定**：沃登动/静、莫卓克躲柱、奥卓克希昂进出领域，依赖位置/状态机，需 `onTick` 强化。  
4. **阶段机**：`BossEncounterModule.onTick` 已预留，影牙亚什布里/斯普林瓦尔、DS 全王应用不足。  
5. **计时器**：高弗雷 `setTimeout` 应改为引擎时钟，便于联机快照与暂停。
