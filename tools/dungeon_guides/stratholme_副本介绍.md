## 1. 概览

- **类型**：5 人副本（经典旧世 55–60；血色侧 / 亡灵侧）
- **位置**：东瘟疫之地；正门进血色区，侧门（城市大门钥匙）进亡灵区
- **主题**：燃烧的城市，血色十字军与天灾对峙。血色线止于巴纳扎尔；亡灵线清三通灵塔后开屠宰场打到瑞文戴尔。可选限时营救男爵（邮差/精英路线）。
- **Boss 顺序**：
  1. 不可宽恕者 / 悲惨的提米 / 炮手威利 / 档案管理员加尔福特 / 巴纳扎尔（血色）
  2. 通灵塔首领们 / 拉姆斯登 / 瑞文戴尔男爵（亡灵）

## 2. 副本流程环节

1. 血色侧（正门）：不可宽恕者 → 悲惨的提米 → 炮手威利（用炮）→ 加尔福特 → 巴纳扎尔
2. 亡灵侧：清三座通灵塔（杀塔内侍僧才算）→ 安娜丝塔丽 / 奈鲁布恩坎 等 → 屠宰场 → 拉姆斯登 → 瑞文戴尔
3. 巴瑟拉斯镇长掉落城市大门钥匙（开侧门）
