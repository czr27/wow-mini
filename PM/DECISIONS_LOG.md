# 📝 重要决策日志（Decisions Log）

> 记录所有重要技术/设计决策，避免AI接手时重复讨论。

---

## D-001 技术栈选型（2026-11-21）
**决策**：TypeScript + React 18 + Tailwind CSS + HTML5 Canvas + Vite + npm workspaces Monorepo  
**原因**：GDD已锁定（见GDD §1.2）  
**影响**：所有前端组件使用React；战斗引擎纯TS可浏览器/Node复用

## D-002 Monorepo 结构（2026-11-21）
**决策**：三包结构 `packages/engine` + `packages/web` + `packages/server`  
**原因**：engine与server共享，web与server解耦  
**影响**：engine零浏览器API依赖（可Node.js直接import）

## D-003 渲染方案（2026-11-21）
**决策**：战斗主画面用原生 HTML5 Canvas 2D；HUD组件用React DOM  
**原因**：Canvas更适合实时像素精灵+粒子特效；React适合HUD状态驱动组件  
**影响**：Canvas层与React层通过共享状态Store（Zustand/Context）通信

## D-004 测试工具（2026-11-21）
**决策**：Vitest（单元测试）+ Playwright（E2E+视觉回归）  
**原因**：Vitest与Vite原生兼容；Playwright支持截图对比画面验证  
**影响**：QA可自动化跑视觉测试截图对比，满足GDD画面验证要求

## D-005 美术风格（2026-11-21）
**决策**：32×32px职业像素精灵；64×64~112×112px Boss像素模型；8帧施法动画  
**原因**：GDD §3.2明确规定像素风  
**影响**：ART目录下所有精灵均为PNG格式，提供spritesheet

## D-006 AI决策频率（2026-11-21）
**决策**：AI行为200ms决策间隔；战斗引擎20Hz（50ms）Tick  
**原因**：GDD §7明确规定  
**影响**：engine每4个Tick触发一次AI决策

## D-007 用户账号与角色持久化系统（2026-11-21）
**决策**：使用 LocalStorage + 服务端双重兼容架构，实现用户注册/登录、角色新建/删除。角色记录：名称、职业、最后使用的天赋（Spec）。
**原因**：用户新增需求，必须支持离线单人与在线多人多角色隔离管理。
**影响**：在 engine types 中加入 UserAccount, CharacterRecord 数据结构，web 端加入 Auth & Character Select 模块。

## D-008 独立天赋快捷键偏好系统（2026-11-21）
**决策**：每个角色按天赋类型（如 DK 鲜血/冰霜，德鲁伊 恢复/平衡）独立存储键位映射表（`specKeybindings: Record<string, KeybindingMap>`）。切换天赋时自动加载该天赋的快捷键习惯。
**原因**：魔兽世界硬核玩家核心需求，不同天赋技能循环完全不同，需要独立快捷键方案。
**影响**：ActionBar 支持快捷键自定义并持久化到角色的天赋配置中。

## D-009 副本通关证明与历史战报道具（2026-11-21）
**决策**：击败最终 Boss 后生成唯一“通关证明（Clear Certificate）”道具放入角色背包/成就库。点击可打开该次副本的完整战报详情（含逐Boss耗时、总耗时、DPS、HPS、有效治疗非Overheal、打断数等）。
**原因**：用户需求“获得奖励（副本通关证明打开可以显示该本统计数据）”。
**影响**：扩展 EncounterReport 与 DungeonClearReward，支持道具化查看历史统计。

## D-010 世界排行榜（World Leaderboards）（2026-11-21）
**决策**：建立三大世界排行榜：
1. **最快击杀某 Boss 榜（Boss Fast Kill Speedrun）**
2. **最高输出榜（Max DPS）**
3. **最高非 Over 治疗榜（Max Effective HPS）**
通关后自动核算上报，支持按职业、按副本、按Boss过滤查看。
**原因**：用户明确需求“副本通关可以有世界排名比如最快击杀某 boss，最高输出或非 over 治疗世界排名”。
**影响**：在 engine 中加入 LeaderboardManager，web 端提供实时排行榜查看面板。

## D-011 仿真动态战斗画面与投射物粒子系统（2026-11-21）
**决策**：Canvas 战斗画面从静态站桩全面升级为高仿真动态打斗：
1. **站位与微位移**：近战（坦、贼、DK）贴近 Boss 挥砍挥击；远程（法师、萨满）与治疗留在后排；全员具备呼吸、轻微走位和躲避毒圈的动作。
2. **投射物与弹道**：法师火球术/炎爆术发射动态飞行弹道投射物并在 Boss 身上爆炸；治疗释放翠绿/水蓝导引光束与治疗链弹跳；近战伴随刀光剑影火花。
3. **直接交互**：Canvas 中的所有角色与 Boss 均支持鼠标直接点击选中，与团队框架完全联动。
**原因**：解决用户反馈“战斗画面完全静态”的问题，提升魔兽打本代入感。

## D-012 完整真实仇恨与 OT 报警机制（2026-11-21）
**决策**：Boss 强制锁定当前最高仇恨存活目标为攻击对象；当坦克死亡或高爆发 DPS/治疗仇恨超过当前仇恨 110%（近战）/ 130%（远程）时触发 OT（仇恨失控）；顶部显示 Boss 当前目标框；团队框架中获得仇恨的目标触发红色呼吸警报边框。
**原因**：真实复刻魔兽世界仇恨机制。

## D-013 真实技能读条、拖拽技能栏与复活机制（2026-11-21）
**决策**：
1. **玩家施法条**：读条技能（如火球术、强效治疗波、愈合、起死回生）必须显示读条进度条，移动或打断会取消读条。
2. **技能栏拖拽与提示**：3×12 技能栏支持鼠标拖拽调换槽位，鼠标悬停显示详尽技能说明 Tooltip。
3. **复活与休整机制**：Boss 死亡立即停止攻击；赶路休整阶段中，存活治疗（AI 德/萨或玩家）必须对阵亡队友读条 3 秒施放复活技能，全员复活齐备后才推进至下一首领。
4. **像素风格职业头像与魔兽原版风格图标**：取代文字方块，绘制职业高辨识度像素头像与技能经典图标。
**原因**：解决用户反馈的 Boss 死后仍放技能、无法复活、UI不够拟真等关键体验缺陷。

## D-014 真实技能效果与机制对齐（HoT/DoT/引导/Buff/减伤）（2026-11-21）
**决策**：
1. **回春术（Rejuvenation）**：12 秒真实持续 HoT，基于 AuraManager 每 3 秒跳血一次（4500基础 + 法强加成）。
2. **生命绽放（Lifebloom）**：支持最多叠 3 层，每秒产生跳血，在持续时间自然结束时“绽放”并瞬间自愈巨额生命。
3. **宁静（Tranquility）**：实现为 8 秒引导施法（isChannel），每 2 秒对全团跳出大额群体治疗，走动自动打断引导。
4. **活动炸弹（Living Bomb）**：12 秒 DoT，持续跳火伤并在结束时触发暴烈爆炸。
5. **防御与增益 Buff**：白骨之盾（6层消耗与真实护盾吸收）、吸血鬼之血（临时上限增加与受疗加成）、切割（攻速+40%）、冲动（能量恢复加速）均产生实际战斗数值收益。
**原因**：彻底根除技能名与实际效果不符的缺陷。

## D-015 影牙城堡 5 首领大地的裂变 4.3 英雄模式机制真实化（2026-11-21）
**决策**：

## D-016 WASD / 方向键全自由走位与走动打断施法（2026-11-21）
**决策**：
1. 玩家可在战斗画布中使用 `W/A/S/D` 或上下左右方向键自由移动。
2. 走动时自动打断当前正在进行的读条施法或通道引导（如火球术、强效治疗波、宁静）。
3. 走位用于躲避地面亵渎毒圈、躲避双枪弹幕扇形危险区、步入百花齐放/治疗之雨法阵受疗，以及在沃登勋爵绿药时保持移动、红药时停步。
**原因**：将完全静态站桩升级为高仿真魔兽打本走位手感。

## D-017 AI 队友智能走位与倾向决策系统（2026-11-21）
**决策**：
1. **近战倾向**：AI 坦克与盗贼紧贴 Boss（维持 65px 近战攻击判定距离）。
2. **远程倾向**：AI 法师、萨满与治疗保持 220px 安全施法距离。
3. **残血寻法阵**：当 AI 角色生命值 < 60% 时，若场上存在百花齐放或治疗之雨绿圈，AI 会主动寻路走近治疗法阵接受跳血。
4. **躲避危险**：当斯普林瓦尔亵渎毒圈或高弗雷弹幕扇形覆盖其坐标时，AI 会主动侧向移出危险区域。
**原因**：实现用户要求的“AI 角色可以有自己的倾向，近战贴脸远程保持施法距离，严重不满血走近治疗法阵”。

## D-025 顺时针钟表走扇形计算法则（2026-11-21）
**决策**：
1. **增益与减益（Buff/Debuff）**：
   - 初始施加时全亮（0°黑色）。
   - 随时间流逝，半透明黑色扇面顺时针从 0° 扩展至 360°（公式：`elapsedDeg = (1 - remaining/duration) * 360`），全黑后刚好自然消失。
   - 叠层 Buff（如生命绽放）：叠至第 2、3 层时角标更新且刷新持续时间；单体 Buff（如回春术）：再次施放保持 1 层，重置持续时间至 12s。
2. **动作栏技能冷却（CD）**：
   - 刚进入冷却时全黑（360°黑色遮罩）。
   - 随 CD 倒计时，黑色遮罩顺时针收缩露出高亮图标（公式：`remainingDeg = (remainingCd/totalCd) * 360`），CD 走完瞬间全亮并伴随金色边框流光。
